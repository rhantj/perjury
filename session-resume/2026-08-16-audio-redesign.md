# 2026-08-16 — 절차적 사운드를 「스산한 법정」으로 다시 설계

> 작업자: B
> 브랜치: `feat/ui-audio-atmosphere` (main 미머지, 미배포)
> 기준 커밋: `3bcd1cc` (merge: 절차적 사운드 합성)

## 배경

`3bcd1cc`에서 들어간 합성 사운드가 **「발랄한 게임 효과음」**으로 들린다는 지적을 받고 전면 재작업.
음원 파일 0개 원칙은 그대로 두고(번들 크기·라이선스), 합성 쪽만 바꿨다.

지적은 네 번에 걸쳐 왔고 그때마다 원인이 달랐다. 이 순서 자체가 기록의 핵심이다.

1. 「밋밋하다」 → 배경음에 **변화가 없었다**(고정 지속음 4겹뿐)
2. 「구리다·발랄하다」 → 효과음이 **장조 상승 아르페지오·조화 배음**이었다
3. 「단조롭다」 → **재료가 부족**했다(사인파는 배음이 1개)
4. 「다 비슷비슷하다」 → **재료를 균일하게 뿌려서** 개성이 지워졌다 ← 여기가 반전 지점

## 완료

### 엔진 — `src/audio/engine.ts` (245 → 668줄)

소리를 만드는 원재료 계층. 아래를 새로 넣었다.

- **절차적 잔향** — 잡음에서 임펄스 응답 생성(3.4초, 앞머리 20ms 공백, 고역이 먼저 죽음).
  IR 파일을 받지 않는 이유는 «음원 0개» 전제와 수백 KB 비용. 배경음·효과음이 같은 방을 쓴다.
- **`bed()`** — 이음매 없는 8초 잡음(등출력 교차 페이드) + 저역통과 차단점 LFO 스윕. 배경음의 «공기».
- **`sustain()` 시그니처 변경** — `(type, hz, gain, target)` → `(spec, target)`. `drift`(음정 흔들림) 추가.
- **`tone.fm`** — 비정수비 주파수 변조. **«풍부함»을 만드는 유일한 장치**(사인파 배음은 1개).
- **`tone.wobble`** — 꼬리 진폭 LFO. 매끈한 감쇠 = 기계, 흔들리는 감쇠 = 남아 있음.
- **`burst.toFrequency`** — 필터 스윕. 고정 필터 = 「틱」, 움직이는 필터 = 「후욱」.
- **`pan`** (tone·burst) — StereoPanner. 구형 사파리는 try/catch로 무시.
- **버스 새추레이션** — `x − 0.28x³`, 4배 오버샘플. 큰 신호만 눌러 3차 배음 생성.
- **`grains()`** — 잡음 알갱이를 시간·음높이(로그)·좌우로 산포. 「부산스러움」의 엔진.
- **`voice()`** — 포먼트 3개 대역통과. 숨·신음. **「스산함」이 결정적으로 갈리는 지점.**

### 악기층 — `src/audio/voices.ts` (신규 249줄)

`synth.ts`가 800줄 상한에 걸려 분리. `engine`=원재료 / `voices`=재료 / `synth`=조립.

`vary`(±센트 무작위) · `ring`(남는 쇳소리) · `metal`(때린 쇠, 비정수비 FM) · `whoosh` ·
`debris`(잔해) · `murmur`(웅성거림) · `breath`/`moan`(포먼트) · `bell`(비조화 배음 종) · `VOWEL`.

`bell`은 배음비 0.5 · 1 · **1.2(단3도)** · 1.5 · 2 · 2.52 · 3.01. 1.2가 종을 구슬프게 만든다.

### 효과음 12종 — `src/audio/synth.ts` (173 → 626줄)

**최종 원칙(4차 지적 이후 뒤집은 것):**

> 자주 나는 소리는 단순하게, 드물게 나는 소리는 풍부하게.
> 각 소리는 길이·음역·밀도·방향 중 **최소 두 축**에서 나머지 전부와 달라야 한다.

파일 상단에 12종 배치표를 주석으로 박아뒀다. **새 소리를 넣거나 고칠 때 그 표의 빈칸을 먼저 본다.**
이미 찬 칸에 하나 더 넣으면 둘 다 흐려진다. 재료 배분도 규칙으로 고정 —
웅성거림은 `round`·`caught`에만, 밝은 파편은 `caught`에만, 쇳소리는 실제 쇠가 있는 자리에만.

바뀐 것 중 큰 것:

| 소리 | 전 | 후 |
|---|---|---|
| `round` | 1:2:3:4 조화 배음(실로폰) | 비조화 배음 종 110Hz + 개정 전 웅성거림 |
| `myTurn` | 587→880→1175 상승(레벨업) | 나무 두드림 2회, 두 번째가 더 낮음 |
| `win` | 도–미–솔–도 장3화음 팡파르 | 종 + 라단조 3화음. **유일하게 닫히는 소리** |
| `challenge` | 사워투스 330→990(오락실) | 400→2000 스윕 + 트라이톤 상승. **유일하게 올라감** |
| `draw` | 7회 상승 클릭(슬롯머신) | 알갱이 22개 산포 → 착지 1회 |
| `caught` | 사각파 배음 | 2단(파열 → 숨 → 24Hz 붕괴) + 전 대역 파편 + 신음 |
| `wrongCall` | 하강 3음 | 27Hz 진폭 변조 버즈(98Hz). **유일한 버즈** |
| `perjury` | 맥놀이 2음 | **타격이 아예 없음**(모든 겹 어택 0.3초+) + 「우」 숨 |
| `lose` | 하강 4음 | 110→22Hz, 음마다 반음 절반씩 처짐, 「어」 신음 174.6→65Hz |

### 배경음 2곡 — `src/audio/drone.ts`

- 공기(`bed`) + 30초 주기 차단점 스윕 + 음정 드리프트 ±5센트 추가 → 「멎어 있음」 해소
- `intro`: 1568Hz 맥놀이 쌍(냉기), 잔향 0.62
- `table`: D–D# 반음 쌍, 트라이톤 간헐음, 맥박을 **2.1초 정박 → 2.6~3.6초 불규칙**(메트로놈 탈피), 잔향 0.46

### 버그 2건

- **`burst` 버퍼 잘림** — 2초 잡음 버퍼의 최대 1.5초 지점부터 읽어 남은 길이가 0.5초뿐이었다.
  0.5초보다 긴 잡음은 볼륨 곡선이 살아 있는데 재생이 먼저 끝나 소리가 도중에 사라진다.
  필요 길이만큼 앞쪽에서만 뜨고, 버퍼보다 길면 `loop = true`. (`engine.ts` `burst`)
- **효과음을 누르면 배경음이 되살아남** — 확인 페이지가 클릭마다 `setMuted(false)`를 불렀는데
  `setMuted`는 게임의 **전체 음소거**라 배경음까지 되살렸다. 근본 원인은 `playBgm`에 짝이 없던 것.
  → **`stopBgm()` 추가**(`audio.ts`). 음소거와 달리 곡만 끊어 효과음은 그대로 들린다.
  게임 화면에서는 아직 호출하지 않으므로 플레이 동작 변화 없음.

## 팀에 전달

- **소리 코드는 3층이다.** `engine.ts`(오실레이터·잡음·필터·잔향) → `voices.ts`(쇠·종·잔해·숨) →
  `synth.ts`(12종 조립). 소리를 고치는 일은 대개 재료가 아니라 **조립**을 고치는 일이라,
  `synth.ts`만 보면 된다.
- **`synth.ts` 상단의 12종 배치표를 먼저 읽을 것.** 각 소리가 「이것만 갖는 것」이 정해져 있다.
  거기 적힌 축(길이·음역·밀도·방향)을 무시하고 재료를 더하면 소리들이 서로 뭉개진다 —
  실제로 이번 작업에서 한 번 그렇게 실패했고, 되돌리는 데 판본 하나가 더 들었다.
- `stopBgm()`이 `audio.ts`에 생겼다. 결과 화면에서 배경음을 끄고 여운만 남기고 싶으면 쓸 수 있다.
- 음원 파일 0개 원칙은 유지. `src/assets/audio/<이름>.mp3`를 넣으면 그쪽이 자동으로 우선한다.
