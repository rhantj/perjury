## 왜 하는가 (이전 → 왜 → 원리)

프록시는 `line`을 돌려주는데 `src/ai/llm-decider.ts`의 `ask()`가 그냥 버리고 있었다.
`Decider` 인터페이스의 반환 타입에 대사가 들어갈 자리가 없었기 때문이다.

곁줄기(store에 `라운드:플레이어 → 대사` 맵을 따로 두기)는 diff가 작아 보이지만,
대사를 만드는 곳이 `flow.ts`라 **flow의 모든 함수가 `{state, lines}`를 돌려줘야** 한다.
번지는 범위는 같은데 상태만 두 갈래로 갈린다. 그래서 엔진 기록에 넣었다.

설계상으로도 이쪽이 맞다 — `Log.tsx:14`에 이미 적혀 있다:
**반증 선언은 원래 «대사»다. 「없습니다」도 진술이고 그래서 위증이 될 수 있다**(설계 §1.4.1).
엔진은 이미 선언을 발화 행위로 취급했고, 빠진 건 «실제로 뭐라고 말했는지»뿐이었다.

## 완료

### 1단계 — 엔진 기록에 대사 자리 (`23feb00`)

- `Declaration.line`, `RoundRecord.suggestionLine`, `ChallengeRecord.line`, `Vote.line`
- 전이 함수는 기본값 `null`: `suggest(..., line = null)`, `challenge(..., line = null)`
- `declareAll(state, claims, lines?)` — **대사를 claims와 다른 인자로 받는다.**
  선언 수 검사·카드 검사가 `claims`만 보면 끝나야 룰과 연출이 한 함수에서 안 엉킨다.
  `claims`는 필수(빠지면 던진다), `lines`는 장식(없어도 되고 선언 안 한 사람 것은 버려진다).
- **시야에도 싣는다**(`view.ts`). 대사는 소리내어 한 말이라 전원이 들었고,
  실어야 에이전트가 남의 말에 반응할 수 있다. `isPerjury`는 계속 시야 밖 —
  «무엇을 말했나»는 공개, «그 말이 참인가»는 비공개다. 테스트로 못 박아 뒀다.

### 2단계 — 판단자가 대사를 함께 돌려준다 (`be195a2`)

- `Spoken<T> = { value, line }`. `Decider` 네 메서드가 전부 이걸 반환한다.
  **대사를 나중에 묻는 메서드를 두지 않은 이유**: Decider는 호출 사이에 상태를 들 수 없다
  (한 인스턴스가 6좌석 대행 → 손패가 샌다). "방금 뭐라 했나"를 묻는 것 자체가 상태다.
- `llm-decider`가 대사를 좁힌다 — 줄바꿈 압축, 60자 절단, 빈 값/비문자열은 `null`.
  **이상한 대사에도 던지지 않는다.** 던지면 `createRoundFallback`이 받아서
  그 라운드 «전체»가 규칙 기반으로 넘어간다. 말 한 줄 때문에 룰 판단을 잃는다.
- 규칙 기반 판단자는 `silent()` — 대사를 만들지 않는다. 여기서 급조하면 폴백이
  LLM 흉내를 내며 같은 문장을 반복한다. 사전생성 대사 풀은 D8 작업이다.

**작업 중 되돌린 것**: `claimsOf` 헬퍼에 `legalClaim`을 넣었다가 **사람의 선언까지
조용히 침묵으로 바뀌는** 구조가 됐다. 좁히는 지점을 호출부로 되돌렸다.
기존 테스트는 이걸 못 잡는다(사람 선언이 합법인 케이스만 있다).

## 팀에 전달

- **대사는 이미 시야에 있다.** UI에서 쓸 곳은 세 군데다:
  `view.rounds[N].suggestionLine` / `declarations[].line` / `challenge.line`.
  없으면 `null`이므로 **지금 고정 문구로 되돌아가는 분기를 반드시 남겨야 한다** —
  사람·규칙 기반 판단자·폴백에는 대사가 없다(절대 규칙 4).
- **`Decider`를 구현하거나 테스트에서 흉내 낼 때 반환 타입이 바뀌었다.**
  `Promise<Claim>`이 아니라 `Promise<Spoken<Claim>>`이다. 대사가 없으면
  `silent(값)`으로 감싼다(`src/ai/decider.ts`).
- **`Vote`에 `line`이 생겼다.** 테스트 픽스처에 `line: null`을 넣어야 타입이 통과한다.
