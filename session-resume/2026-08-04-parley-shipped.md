> 일정: D5 / 마감까지 D-6

## 한 줄 요약

**밀담이 실제로 돈다.** 플레이어가 AI 한 명과 1왕복 대화하고, 오간 말은 **그 상대의 다음 프롬프트로만** 되돌아간다.

---

## 무엇이 생겼나

설계 §3이 밀담에 달아둔 한 줄 — "여기서 LLM이 진짜 일한다" — 이 실현됐다.
지금까지 LLM이 한 일은 구조화된 선택(카드 하나, 대상 하나)이었고 대사는 장식이었다.
밀담은 **자유 텍스트가 양방향으로 오가는 유일한 지점**이다.

구조는 «한 번의 전이»다. 프론트가 「상대 지목 → 내 말 → 상대의 답」을 다 받아온 뒤
`parley()`를 한 번 부른다. 두 번의 전이로 나누면 「말했는데 답이 안 왔다」가 상태로 남아
응답이 안 올 때 페이즈가 갇힌다 — 이미 두 번 겪은 버그와 같은 종류다.

밀담 페이즈의 출구는 `parley`와 `skipParley` **둘뿐이고 둘 다 라운드를 끝낸다.**
그래서 갇힐 자리가 구조적으로 없다.

설계 근거는 [docs/decisions/005-밀담-기록-위치.md](../docs/decisions/005-밀담-기록-위치.md),
스펙은 [docs/superpowers/specs/2026-08-04-parley-design.md](../docs/superpowers/specs/2026-08-04-parley-design.md),
계획은 [docs/superpowers/plans/2026-08-04-parley.md](../docs/superpowers/plans/2026-08-04-parley.md)에 있다.

## 딸려 온 것 — 에이전트가 서로의 말을 못 읽고 있었다

밀담이 성립하려면 관측 기록에 오간 말이 실제로 들어가야 한다. 그런데 `observationBlock`이
`claimText(d.claim)`만 렌더하고 `line`을 통째로 무시하고 있었다. **대사를 화면에만 띄우고
프롬프트에는 안 넣고 있었던 것이다.** 밀담과 함께 고쳤다.

룰 블록에도 두 줄을 넣었다. `setup.ts`가 `player.name`을 용의자 카드 이름으로 그대로 쓰는데
룰이 그 관계를 한 번도 설명한 적이 없어서, 「강도윤이 강도윤 카드를 안 갖고 있다니 거짓말이군」
같은 틀린 추론이 나올 수 있었다. **밀담의 첫 용도가 해명**이므로 이 줄이 없으면 해명이 통하지 않는다.

https://rhantj.github.io/perjury/ 에서 실제로 돌렸다.

| 확인 | 결과 |

| **오간 말이 되돌아가는가** | 다음 라운드 밀담에서 상대가 자기가 한 말을 그대로 기억했다 |
| **제3자 격리** | 아래 별도 항목 |

| 폴백 라운드 | 패널이 처음부터 닫히고 넘어가는 문만 남는다 |

### 격리는 요청 본문으로 직접 봤다

화면에 물어보는 것으로는 부족하다 — **새도 화면에 아무 표시가 안 난다.**
`window.fetch`를 감싸 워커로 나가는 본문을 기록했다.

```
라운드 2 suggest / viewer p1 (밀담 상대) → parley 실렸다
라운드 2 refute / viewer p2·p3·p4·p5     → 전부 null
```

## 실플레이에서 잡은 고장 셋

배포 링크에서만 드러난 것들이다. **typecheck도 테스트도 잡아주지 않았다.**

1. **폴백 라운드인데 패널이 열려 있었다** (`fix` 커밋)
   `blocked` 플래그를 «내 차례가 아닐 때» 분기 안에서만 읽고 있었다. 그래서 폴백인데도
   상대를 고르고 200자를 쓰고 기다린 **뒤에야** 「이뤄지지 않았다」가 떴다. 헛수고를 시킨다.
   **닫되 넘어가는 문은 남겼다** — 라운드를 넘기는 것이 밀담의 두 출구뿐이라, 버튼을 빼면 판이 갇힌다.

2. **패널이 잘려 출구가 화면 밖으로 나갔다** (`fix` 커밋)
   `.screen`이 `100dvh` + `overflow:hidden`이고 `.board`가 `align-items:start`라,
   밀담 패널이 단계마다 커지면 **스크롤이 아니라 잘려서 사라졌다.**
   `.stage`에 `max-height:100%; overflow-y:auto`를 줬다. `max-height`가 있어야 `auto`가 실제로 걸린다.

3. **「참가3와」** (`fix` 커밋)
   `josa()`에 와/과가 없어서 Log에 직접 박았다. 3은 「삼」이라 ㅁ받침이므로 「참가3과」다.
   `josa(말, 'wa')`를 추가했다.

## 팀에 전달

- **`GameView`에 필드를 더하면 `workers/src/schema.ts`를 반드시 함께 고친다.**
  화이트리스트라 모르는 필드는 거부되고, 그러면 워커가 200에 `{"ok":false}`를 돌려주며
  폴백이 그걸 삼킨다. **typecheck도 테스트도 안 잡아준다. 배포본 클릭만이 잡는다.**
- **배포 직후 확인할 때 `index.html`이 캐시돼 옛 자산을 물 수 있다.**
  이번에 CSS 수정이 반영 안 된 것처럼 보였는데 브라우저가 옛 번들을 들고 있었다.
  `?v=2` 같은 쿼리를 붙이거나 강제 새로고침으로 확인한다.
- **화면에 한국어 문구를 쓸 때 조사를 직접 박지 않는다.** `josa(말, 'ro'|'eul'|'i'|'eun'|'wa')`.
- **밀담 패널처럼 «자라는» 영역을 `.stage`에 넣을 때 잘림을 확인한다.** `.screen`은 `overflow:hidden`이다.
