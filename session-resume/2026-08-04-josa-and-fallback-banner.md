## 완료

### 1. 조사 처리 (`c7f7461`)

**범위를 앞선 기록보다 넓게 잡아야 했다.** 처음엔 「대리석 문진로」 하나로 봤는데,
코드가 `` `${label}로` ``로 고정이라 **받침 있는 카드는 전부 틀리고 있었다.**
서재·명주 목도리처럼 받침이 없거나 ㄹ받침인 것만 우연히 맞았다.

```
나가 … 옥상를 올렸다   →  내가 … 옥상을 올렸다
강도윤로 반증합니다     →  강도윤으로 반증합니다
```

`src/content/josa.ts` 순수 함수 하나로 처리하고 화면 문구 8곳에 적용했다. 규칙은 셋이다.

- **로/으로만 ㄹ받침을 「받침 없음」처럼 다룬다.** `응접실로`이지만 `응접실을`이다.
  이 한 줄이 로/으로를 나머지 조사와 갈라놓는 전부다.
- **숫자로 끝나면 읽는 소리를 따른다.** 좌석 이름이 `참가1`이라 필요하다 —
  「참가일」이라 ㄹ받침이라 `참가1이`, 「참가이」인 2는 받침이 없어 `참가2가`.
  글자 모양만 보면 둘 다 받침이 없어 보인다.
- **「나」만 예외.** `나가`가 아니라 `내가`다. 조사가 아니라 대명사가 통째로 바뀌므로
  함수로는 못 만들고 호출부(`Log.tsx`의 `subject()`)에서 갈랐다.

테스트 6개. 「아편팅크는 받침이 없다」를 따로 둔 이유 — 「크」는 ㅋ으로 시작할 뿐 받침이 없다.
글자 모양만 보고 판단하면 틀리는 예라서 회귀 방지로 남겼다.

### 2. 폴백 표시 (`fece106`)

상단 우측에 `代 연결 끊김 — 규칙으로 진행`. **편의 기능이 아니라 진단 장치다** —
직전 세션에서 워커가 요청을 거부하는 동안 판은 멀쩡히 끝났고, 화면만 봐서는
「대사가 안 뜬다」로만 보였다. 폴백이 조용하면 LLM이 죽어도 아무도 모른다.

- 문구를 사유로 가른다. `budget`은 그날 안에 안 낫고 `error`는 다음 라운드에 나을 수 있다.
- 경고색(빨강)은 쓰지 않았다. 게임은 정상 진행 중이고, 빨강은 위증 연출이 이미 쓴다.
- store는 `fallbackRound`/`fallbackReason`을 이미 내주고 있었다(테스트도 있었다).
  **화면이 읽지 않았을 뿐이다.**

## 정정 — 좌석 발언은 «병기»가 아니라 «대체»다

직전 기록([llm-line-shipped](2026-08-04-llm-line-shipped.md))에 **「고정 문구를 대체하지 않고
병기한다」**고 적었다. **좌석은 더 이상 그렇지 않다.** B가 `93b57e8`로 바꿨고, 그대로 간다.

- **좌석**(`Table.tsx`) — 대사가 있으면 **대사만**. 없을 때(사람·규칙 기반 판단자·폴백)만 고정 문구.
- **기록 서랍**(`Log.tsx`) — 고정 문구와 대사를 **나란히** 둔다. 지금도 그렇고 그대로 둔다.

**왜 둘이 다른가.** 좌석은 칸이 좁아 두 줄이 겹치면 네 줄까지 간다(실제로 그렇게 나갔다).
그리고 반증한 좌석에는 **반증 카드 그림이 이름과 함께 따로 뜨므로**(`seat__reveal-card`)
무엇으로 반증했는지가 사라지지 않는다. 기록에는 그 그림이 없고 폭도 넉넉하며,
**되짚어 보는 곳**이라 「무엇으로 반증했나」가 곧 추리의 근거다.

**남는 위험**: 침묵(`없습니다`) 좌석에는 카드 그림이 없다. 대사가 모호하면
「이 사람은 없다고 했다」가 화면에서 흐려진다. 배포본에서 볼 것.

## 검증

**폴백 배너는 배포 링크에서 확인할 수 없다.** 정상 상태에선 안 뜨는 게 정상이기 때문이다.
로컬 `npm run preview`에서 프록시를 죽여서 봤다:

```js
const orig = window.fetch
window.fetch = async (...a) => {
  if (String(a[0]).includes('/decide')) throw new TypeError('주입된 실패')
  return orig(...a)
}
```

조사는 배포 링크에서 실제 문장으로 확인했다 —
`내가 강도윤 · 대리석 문진 · 옥상을 올렸다` / `강도윤으로 반증합니다` / `대리석 문진으로 반증합니다`.

## 팀에 전달

- **화면에 한국어 문구를 새로 쓸 때 조사를 직접 박지 않는다.** `josa(말, 'ro' | 'eul' | 'i' | 'eun')`을 쓴다.
  카드·좌석 이름은 데이터라 받침이 제각각이고, 템플릿에 박으면 반드시 틀린다.
- **폴백 배너가 뜨면 그 판의 AI는 규칙 기반이다.** 심사 시연 중에 이게 보이면
  LLM 경로가 끊긴 것이니 워커부터 확인한다(`curl .../health`).
