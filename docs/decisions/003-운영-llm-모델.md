# 운영 LLM 모델을 Sonnet 5로 정한다

- 날짜: 2026-08-03
- 관련 브랜치: `feat/proxy-anthropic-adapter`

## 맥락

프록시 배선은 끝났지만 어떤 모델을 붙일지가 비어 있었다. 후보를 재는 축이 셋이었다.

1. **품질** — 이 게임에서 LLM이 실제로 해야 하는 판단을 해내는가
2. **지연** — 반증 페이즈는 5명이 동시에 나간다. 프록시 상한이 25초다
3. **비용** — 심사 기간 내내 켜 둬야 한다

Claude Max 구독은 API에 적용되지 않고 HF PRO 크레딧은 소진돼 있었으므로,
어느 경로로 가도 별도 결제가 필요했다. Anthropic API 키를 쓰기로 정한 뒤 모델을 골랐다.

## 무엇을 쟀나

같은 상황을 세 모델에 던졌다. **내가 범인이고, 제안된 세 장이 봉인된 정답 그 자체이며,
내 손에는 그중 아무것도 없는 자리.** 정직하게 넘기면 다음 순간 정답이 드러난다.
게임 이름이 「위증」인 이유가 되는 순간이다.

| 모델 | 판단 | 대사 | 응답 | 판당(≈90회) |
|---|---|---|---|---|
| Haiku 4.5 | 넘김 (3회 중 1회는 `refute`+`none` 모순) | 현대 말투 | 2초 | $0.13 |
| **Sonnet 5** | **위증** | **"내 손에 있소"** | **7초** | **$0.5** |
| Opus 5 | 위증 | "있소이다" | 14초 | $1.7 |

## 선택

**`claude-sonnet-5`.** 워커 `LLM_MODEL` 환경변수로 지정한다.

품질에서 Opus와 갈리지 않았다. 위증 판단도, 대사와 행동의 일치도, 시대 말투도 같았다.
비용은 3분의 1, 응답은 절반이다. 25초 상한에 여유가 크다.

## 버린 대안

**Opus 5** — 품질이 같은데 3배 비싸고 2배 느리다. 다만 비용이 결정 요인은 아니었다.
심사 기간 50판을 돌려도 $85로, 감당 못 할 금액이 아니다. **지연이 더 컸다.**

**Haiku 4.5** — 판당 $0.13으로 압도적으로 싸지만 **세 번 중 한 번 위증을 건너뛰었다.**
`kind: "refute"`에 `cardId: "none"`이라는 모순된 조합을 냈고, 우리 `toDecision`이 이를
넘김으로 흡수한다. 게임은 안 깨지지만 **핵심 기능이 조용히 사라진다.** 말투도 현대체로 빠진다.

## 함께 정해진 것

**프롬프트에 [전략] 블록을 넣는다.** 모델 등급보다 이쪽 효과가 컸다.
보강 전 Sonnet은 w1으로 위증해 놓고 "가지고 있지 않소"라고 말해 스스로 블러프를 무너뜨렸다.
세 줄을 넣자 판단·대사가 모두 맞았고 출력 토큰이 574 → 305로 줄었다.
이 블록은 여섯 좌석 공용 캐시 프리픽스에 들어가므로 진영을 조건문으로 쓴다.

## 되돌리는 법

`workers/wrangler.toml`의 `LLM_MODEL`을 바꾸고 `npm run worker:deploy`. 코드 변경이 없다.
프론트는 모델을 모른다.

다시 재려면 계측 창이 열려 있다 — 응답 헤더 `X-Upstream-Tokens`가 `입력/출력/캐시적중`이다.
