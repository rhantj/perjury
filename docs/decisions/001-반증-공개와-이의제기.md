# 반증을 공개 선언으로 바꾸고, 위증 발각에 이의제기를 도입한다

- 날짜: 2026-08-01
- 커밋: (이 문서와 같은 커밋)
- 영향 범위: 룰 엔진 상태 모델, LLM 판단 항목, 추리표 UI

## 맥락

`docs/01-game-design.md`가 스스로 모순되어 있었다.

- §3은 "비공개 공개는 클루 원본 그대로"라고 적었다.
- §1.4는 "장미가 '서재 카드 있어요'라고 반증했다. 그런데 내 손에도 서재 카드가 있다 →
  거짓말쟁이로 확정"이라는 예시를 들었다.

둘은 양립하지 않는다. 반증 내용이 비공개면 제3자는 무엇으로 반증했는지 모르므로
모순을 발견할 수 없다. **발각 경로가 없으면 거짓말 비용이 0이 되고, 최적 전략이
"항상 거짓 반증"으로 수렴해 게임이 붕괴한다.** 페널티를 아무리 무겁게 설계해도
발동되지 않으므로 의미가 없다.

동시에, 발각을 엔진이 자동 공표하면 플레이어가 관전자가 된다는 문제도 있었다.
"교란·교섭이 주가 되는 게임"인데 정보를 쥐고 있을 선택지가 없다.

## 선택

**1. 반증은 테이블 전체에 공개 선언한다.** 실물 확인 절차는 없다.

"나는 서재로 반증한다"를 모두가 듣는다. 그것이 사실인지는 즉시 확인되지 않고,
자기 손패와 모순될 때만 알 수 있다. 제목 "위증(僞證) = 공개 선서 후의 거짓 진술"과
룰이 일치하게 된다.

**2. 발각은 이의제기로만 공식화된다.**

| 상황 | 결과 |
|---|---|
| 이의제기 성공 | 위증자 손패 1장 공개 + 고발자가 근거 카드를 공개 |
| 이의제기 실패 | 고발자 손패 1장 공개 |
| 이의제기 안 함 | 아무 일도 없음 — 알고 있다는 사실은 본인만 안다 |

잡는 데도 비용이 든다. "아는 것"과 "말하는 것"이 분리되어 밀담에 협상 재료가 생긴다.

**3. 역할 분리는 유지된다.** 위증 여부 판정은 손패 대조라 결정론적이며 엔진이 한다.
LLM은 "알지만 지금 말할 것인가"만 판단한다.

## 버린 대안

| 대안 | 버린 이유 |
|---|---|
| 클루 원본대로 비공개 유지 | 발각 경로가 없어 거짓 반증 메커니즘 자체가 무의미해진다 |
| 종류만 공개 ("장소 카드로 반증") | 발각 확률이 낮아 위증 비용이 여전히 헐값. 룰만 복잡해진다 |
| 페널티 A — 신뢰도 하락만 | 마지막 라운드 위증은 비용이 0. 최종 고발 직전이라 가장 중요한 구간에서 무너진다 |
| 페널티 B — 자동 감지 후 손패 공개 | 종반 문제는 막지만 플레이어가 관전자가 된다. 잡는 판단이 게임에서 빠진다 |
| C + B 병행 (미발각분 라운드 말 자동 공표) | 이의제기의 가치가 줄어든다. 어차피 드러날 것을 굳이 비용 들여 잡을 이유가 없어진다 |

## 되돌리는 법

| 되돌릴 것 | 건드릴 곳 |
|---|---|
| 반증 공개 → 비공개 | 반증 이벤트에서 카드 ID를 전체 로그가 아닌 제안자 시야에만 기록. 이의제기 전체가 무의미해지므로 함께 제거해야 한다 |
| 이의제기 제거 | 이의제기 액션과 판정 함수 삭제, 자동 감지로 대체. 손패 공개 로직은 그대로 재사용 가능 |
| 페널티 강도 조절 | 공개 장수(1장)만 상수로 바꾼다. 룰 구조는 유지된다 |

**되돌리기 난이도는 비대칭이다.** 페널티 강도는 상수 하나지만,
공개/비공개는 상태 모델의 가시성 설계라 뒤집으면 이의제기·추리표·AI 컨텍스트가 함께 바뀐다.
D8 밸런싱에서 손댈 곳은 상수 쪽이다.

## 확정 수치

카드 6/4/5 = 15장, 손패 2장씩, 공개 페널티 1장.
카드 수는 목업 검증 결과 추리표가 한 화면에 들어가는 상한이다 — 상세는
`docs/01-game-design.md` §7.
